현재 제공하는 연습

언어이해·자료해석·창의수리·언어추리·수열추리 각 6문항, 총 30문항입니다. 직접 제작한 고정 문항으로, 다시 시작해도 같은 문제가 나옵니다. 실제 기출문항이 아니며 실제 시험과의 난도·유사도는 검증되지 않았습니다.

시간과 이동

시간 제한 모드는 영역별 4분 30초입니다. 시간 종료 또는 영역 제출 후에는 해당 영역으로 돌아갈 수 없습니다. 다음 영역은 준비 화면에서 시작합니다. 자유 연습은 시간 제한 없이 풀 수 있습니다.

메모와 계산기

오른쪽 메모장·그림판과 사칙연산 계산기를 사용할 수 있습니다. 숫자 1–5로 답을 선택하고, Alt + ← / →로 문항을 이동합니다. 입력란을 사용 중일 때는 문항 단축키가 작동하지 않습니다.

저장 범위

진행 중인 답안과 메모, 채점 결과는 이 탭이 열려 있는 동안만 유지됩니다. 새로고침하거나 탭을 닫으면 초기화됩니다. 답안은 서버로 전송하지 않습니다.

구성 참고 자료

5개 인지 영역과 공개 응시 후기를 참고했습니다. 현재 지원 전형의 검사 구성·시간·허용 도구는 개별 응시 안내를 우선해 주세요. 심층역량 연습은 포함하지 않습니다.
