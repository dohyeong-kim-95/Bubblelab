# SKTEST — SKCT 연습실

주소: https://sktest.bubblelab.dev

PC에서 사용하는 개인용 임시 SKCT 인지역량 연습실. 루트 `sktest/`를 기존
와일드카드 Worker가 서빙하므로 별도 DNS·Worker·Sites 프로젝트가 필요 없다.

- `CONFIDENTIAL_SUBDOMAINS`에 등록해 랜딩·풀다운·검색에 노출하지 않는다.
- 로그인은 없으며 주소를 아는 사람은 접근할 수 있다. Worker가 모든 응답에
  `no-store`·`noindex, nofollow`를 붙이고 방문 집계에서 제외한다.
- 휴대폰·태블릿은 PC 안내 화면으로 막는다. PC 창 너비는 1,024px 이상이어야 한다.
  UA·화면·터치 정보를 이용한 브라우저 제한으로, 위장 접속을 막는 인증 수단은 아니다.
- 답안·메모·결과는 탭 메모리에만 남고 새로고침하면 초기화된다. 서버 전송은 없다.

## 기능과 문항

언어이해·자료해석·창의수리·언어추리·수열추리 각 6문항, 총 30문항의 고정
자체 제작 기초 연습 세트다. 실제 기출이나 실전 난도 검증 문항으로 표시하지 않는다.
전체 또는 한 영역, 영역별 4분 30초 제한 또는 자유 연습을 선택한다.
메모·그림판·사칙연산 계산기, 답 표시, 자동 제출, 채점·해설을 제공한다.

기출·복원 자료 메뉴는 공개 원문 링크와 자료 성격을 안내한다. 별도로 확보한
출판사 공개 미리보기 원본과 개인 참고용 압축파일은 이 공개 저장소에 싣지 않는다.

## 파일과 검증

`index.html`·`style.css`·`app.js`는 화면, `core.js`는 기기 판별·타이머·채점·계산기,
`questions.js`는 문항이다. 외부 폰트 없이 실행한다. PDF.js 6.3.289는 버전을 고정한 npm 의존성으로
설치하고 빌드가 라이선스·CMaps·폰트·WASM과 함께 같은 출처에 배치한다.
PDF 이미지 디코딩용 WASM 허용은 sktest 호스트에만 적용한다.

`npm test`의 `_infra/sktest.test.mjs`가 라우팅·집계 제외·PC 판별·채점을 검사하며
빌드 미노출 검사는 `_infra/home-button.test.mjs`에 모은다. 로컬 화면은 빌드 후
`node _infra/csp-serve.mjs`의 `/sktest/`에서 확인한다. 배포는 루트 `make ship`.

## PDF 연습실 (`workbook/`)

[hyunji24의 제작기](https://velog.io/@hyunji24/대기업-인적성-SKCT-시뮬레이션-개발)의
PDF·OMR 통합 방식, 패널 숨기기, 정답표 채점, 풀이 도구를 참고해 별도로 구현했다.
화면이나 코드를 복제하지 않았다.

- 내 PDF를 선택해 페이지 이동·폭 맞춤·50–300% 확대. 한 페이지씩 렌더링해 메모리를 제한한다.
- 20/100문항 OMR. 같은 답을 다시 누르면 취소. 정답은 쉼표·공백·줄바꿈으로 입력한다.
- 5/15/20/100분 또는 자유 연습. 벽시계 기반 종료, 일시정지, 종료·채점 후 답안 잠금.
- PDF/OMR 개별 숨기기, 전체화면, 메모·그림판, 한 획 취소·지우개, 계산기.
- 파일은 최대 100MB이며 로컬 바이트로만 읽는다. 서버 업로드·문제 수집 API가 없다.
- 새 연습은 PDF를 유지하고 답안·풀이·타이머를 초기화한다. 새로고침은 모두 초기화한다.
- PDF 자체의 DRM·비밀번호 해제 기능은 제공하지 않는다.
