말이 아니라 결과물로

아래는 전부 지금 바로 써볼 수 있는 실제 결과물입니다.

  • slop — 미니게임 20여 종, 주간 신기록판·공유 기능 포함
  • util — 네컷사진·플래너·운세·이미지 변환 같은 생활 도구
  • assets — 스티커 팩·배경화면·음원 카탈로그
  • games — 실시간 멀티플레이 보드게임

진행 방식

  1. 아래 폼에 만들고 싶은 것과 회신받을 연락처(이메일 등)를 남깁니다.
  2. 보통 1~2일 안에 실제로 열리는 시안 URL로 회신드립니다. 여기까지 무료입니다.
  3. 시안이 마음에 들면 범위·비용을 정하고, 피드백을 반영해 완성합니다. 결과물은 코드 이관 또는 호스팅 대행 중 원하는 방식으로 드립니다.
