# puzzle — 광고에서 본 그 게임들

상태: **Experiment**. 규칙·스테이지 구성이 예고 없이 바뀔 수 있습니다.

<https://puzzle.bubblelab.dev>. 모바일 게임 가짜 광고에만 존재하던 게임들을
**진짜로** 만들어 모으는 곳입니다. 광고는 거짓말이었지만 여기 있는 건 전부
플레이 가능합니다. 사이트 루트의 카드 목록은 빌드 시 자동 생성됩니다.

## 현재 게임

| 경로 | 원본 광고 장르 | 주간 기록 |
| --- | --- | --- |
| `gaterunner/` | 게이트 러너 (×2/+10 문 고르기) | 클리어 스테이지 최대 |
| `pullpin/` | 핀 뽑기 구출 (Pull the Pin) | 클리어 스테이지 최대 |
| `savedog/` | 벌떼에서 강아지 구하기 (선 긋기 방어) | 클리어 스테이지 최대 |
| `watersort/` | 물 색깔 분류 (Water Sort) | 클리어 스테이지 최대 |

`pullpin`은 핀을 뽑아 보물을 냄비에 담고, 용암은 배수구로 흘려보내거나
건드리지 않고 남겨두는 물리 퍼즐입니다. 용암이 냄비에 들어가거나 보물이
모자라면 실패하며, 손제작 10개 스테이지 이후에는 필요 보물 수가 늘어난 채로
순환합니다.

`watersort`는 시험관 맨 위 물을 같은 색 위나 빈 관에만 부어서 관마다 한
색으로 정리하는 퍼즐입니다. 스테이지는 시드 고정 절차 생성이라 모두가 같은
판을 받고, 생성 시 내장 솔버로 풀이 가능성을 검증합니다. 되돌리기는 무제한,
막히면 언제든 재시작할 수 있습니다.

`gaterunner`는 좌우 드래그로 ×2/+N(초록)과 −N/÷2(빨강) 문을 골라 군중을
불리고 마지막 빨간 군단과 정면 대결하는 러너입니다. 스테이지는 시드 고정
생성이며, 생성 시 그리디 시뮬레이션(매 문마다 더 좋은 쪽 선택)의 결과보다
보스를 약하게 잡아 합리적으로 고르면 항상 이길 수 있게 보장합니다. 군중이
0명이 되거나 보스보다 적으면 실패합니다.

`savedog`는 잉크 예산 안에서 분홍 선을 그어 벽을 만들고, 벌떼가 5초 동안
강아지에게 닿지 못하게 막는 방어 퍼즐입니다. 벌은 강아지를 향해 탐욕적으로
날며 벽을 타고 미끄러지므로 빈틈이 있으면 돌아 들어옵니다. 강아지·벌집
근처에는 선을 그을 수 없습니다. 손제작 8스테이지가 순환하며 돌수록 벌이
빨라지고 많아집니다(잉크는 그대로 — 풀이 가능성 유지).

## 양산 규칙

- 토이 관례는 slop과 동일: 폴더 하나 = 게임 하나, 바닐라 단일 `index.html`,
  첫 이모지 = 카드 아이콘, share.js + `blWeekly`/`blWeeklyReport` + `_infra/records.js`
  `GAMES` 등록.
- 공통 컨셉: 따뜻한 톤(#f6ead8/#1a1626), ui-monospace, "광고는 가짜지만 이건
  진짜임" 자기소개, 실패 문구는 광고 드립.
- 기록은 전부 `클리어 스테이지 최대`로 통일해 명예의 전당에서 비교 가능하게.
- 스테이지는 무한(순환 또는 절차 생성)으로, 뒤로 갈수록 빡빡해지게.
