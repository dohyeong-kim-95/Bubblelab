# puzzle — 광고에서 본 그 게임들

상태: **Experiment**. 규칙·스테이지 구성이 예고 없이 바뀔 수 있습니다.

<https://puzzle.bubblelab.dev>. 모바일 게임 가짜 광고에만 존재하던 게임들을
**진짜로** 만들어 모으는 곳입니다. 광고는 거짓말이었지만 여기 있는 건 전부
플레이 가능합니다. 사이트 루트의 카드 목록은 빌드 시 자동 생성됩니다.

## 현재 게임

| 경로 | 원본 광고 장르 | 주간 기록 |
| --- | --- | --- |
| `fillfridge/` | 냉장고 채우기 (배치 퍼즐) | 클리어 스테이지 최대 |
| `gaterunner/` | 게이트 러너 (×2/+10 문 고르기) | 클리어 스테이지 최대 |
| `icebreak/` | 얼음 깨서 보석 꺼내기 | 클리어 스테이지 최대 |
| `picklock/` | → slop/lockrush 이정표 (스코어제로 승격) | — |
| `trafficjam/` | 트래픽 잼 탈출 (Rush Hour) | 클리어 스테이지 최대 |
| `hall-of-fame/` | 전체 게임 스테이지 총합 랭킹 | 조회·등록 화면 |
| `parkmaster/` | 주차 마스터 (경로 그리기) | 클리어 스테이지 최대 |
| `pullpin/` | 핀 뽑기 구출 (Pull the Pin) | 클리어 스테이지 최대 |
| `savedog/` | 벌떼에서 강아지 구하기 (선 긋기 방어) | 클리어 스테이지 최대 |
| `screwout/` | 나사 풀기 (판자 해체 색 분류) | 클리어 스테이지 최대 |
| `watersort/` | 물 색깔 분류 (Water Sort) | 클리어 스테이지 최대 |

`pullpin`은 핀을 뽑아 보물을 냄비에 담고, 용암은 배수구로 흘려보내거나
건드리지 않고 남겨두는 물리 퍼즐입니다. 스테이지 1~10은 손제작 시그니처,
11+는 모듈 문법 **자동 생성**: 보물 선반(평평·좌우 기울기), 용암+배수구
(좌/우 랜덤), 분할 보물(가운데 벽 + 핀 2개), 분할 함정(좌/우 미러, 전 층)
을 줄 높이 지터와 함께 조합합니다. 게임과 동일한 물리(stepWorld 단일
소스)로 헤드리스 시뮬레이션을 돌려 "아래→위, 배수구 먼저" 솔루션이
실제로 통하는 판만 채택하고, need는 시뮬 수집량-2로 역산해 수집 부족
실패를 원천 차단합니다. 맨 아래 분할 함정은 깔때기 직결이라 뽑으면 즉시
용암 입수, 위층 분할 함정은 뽑으면 용암이 아래층에 얹히는 지연 함정입니다.

`watersort`는 시험관 맨 위 물을 같은 색 위나 빈 관에만 부어서 관마다 한
색으로 정리하는 퍼즐입니다. 스테이지는 시드 고정 절차 생성이라 모두가 같은
판을 받고, 생성 시 내장 솔버로 풀이 가능성을 검증합니다. 되돌리기는 무제한,
막히면 언제든 재시작할 수 있습니다.

`gaterunner`는 좌우 드래그로 ×2/+N(초록)과 −N/÷2(빨강) 문을 골라 군중을
불리고 마지막 빨간 군단과 정면 대결하는 러너입니다. 광고 원본처럼 **진짜
3D**(three.js — CDN 없이 `_shared/vendor/` 셀프호스팅, 빌드 도구 불필요)로
그리고, 게임 로직·생성기·기록·테스트 훅은 2D 시절과 완전히 동일합니다
(WebGL 미지원 기기는 안내 문구). 스테이지 4+에는 군중
일부를 요구하는 **중간 보스**(최대 3), 스테이지 3+에는 회피 가능한 약한
**탄막**(피격 시 군중 손실, 짧은 무적)이 추가됩니다. 생성 보장: 그리디
시뮬레이션에 중간 보스 비용을 반영하고, 탄막 최대 피격 예산을 가정해도
모든 중간 보스를 25% 헤드룸으로 넘고 최종 보스를 이기는 판만 채택. 탄막은
편마다 최소 한 차선이 항상 비는 패턴만 나와 회피가 언제나 가능합니다.

`savedog`는 잉크 예산 안에서 분홍 선을 그어 벽을 만들고, 벌떼가 5초 동안
강아지에게 닿지 못하게 막는 방어 퍼즐입니다. 스테이지는 시드 고정 **역방향
생성**(무한): 강아지를 두른 방을 먼저 짓고 일부러 틈을 1~5개 낸 뒤 잉크를
"틈 막는 데 필요한 길이 × 슬랙"으로 주므로 풀이 존재가 보장되고, 벌집을
각 틈에 정조준 배치해 안 막으면 반드시 물리는 것도 보장됩니다. 돌수록 틈이
늘고 벌이 빨라지며 잉크 슬랙이 조여집니다.

`parkmaster`는 차마다 같은 색 P까지 경로를 그린 뒤 전 차량이 동시에 출발하는
주차 퍼즐입니다. 속도가 같으므로 경로 길이가 곧 타이밍 — 교차 지점을 길이
차이로 비껴가야 합니다. 부딪히면 실패, 전부 주차하면 클리어. 스테이지는
시드 고정 **자동 생성**(무한): "k번째 차는 전용 대기 구역에서 맴돌다 앞선
차들이 주차한 뒤 출발"이라는 구성적 풀이가 성립하도록 구역·경로·주차칸의
기하 여유를 검사하고, 직선끼리 가까이 지나는 쌍 수로 난이도를 강제합니다.
1대(스테이지 1)에서 5대(14+)까지 늘어납니다.

`screwout`은 겹쳐 쌓인 나무 판자의 나사를 풀어 상자 색에 맞춰 3개씩 담는
해체 퍼즐입니다. 위에 판자가 덮인 나사는 풀 수 없고, 색이 안 맞는 나사는
5칸 임시 트레이로 — 트레이가 넘치면 실패. 나사가 다 빠진 판자는 떨어져
아래층이 드러납니다. 스테이지는 시드 고정 **역방향 생성**(추출 가능 순서를
먼저 시뮬레이션한 뒤 그 순서를 3개씩 끊어 상자 색을 배정)이라 모든 판이
트레이 없이도 풀리는 경로를 구조적으로 보장합니다.

`icebreak`는 곡괭이 횟수 제한 안에서 얼음을 깨 보석을 전부 꺼내는 발굴
퍼즐입니다. 한 번 찍으면 그 칸에 2, 상하좌우에 1 데미지가 들어가므로 폭탄
근처를 함부로 찍으면 스플래시가 누적돼 터집니다. 생성기가 "보석 칸만 정확히
직격하는 플레이는 항상 안전하고 곡괭이도 충분하다"를 보장합니다(폭탄 인접
보석들의 직격 스플래시 합 < 폭탄 얼음 두께).

`trafficjam`은 6×6 격자에서 차를 밀어 노란 택시를 출구로 빼내는 러시아워
퍼즐입니다. 내장 BFS 솔버로 풀이 가능성과 최단 이동 수를 검증하며 생성하고,
스테이지가 오를수록 차가 많아지고 최단 해가 길어집니다. 실패는 없고 이동
수와 최단 수를 함께 보여줍니다.

`picklock`(자물쇠 따기)은 스테이지제보다 스코어제가 어울려서 **자물쇠
러시**로 개편해 slop으로 승격했습니다(`slop/lockrush/` — 단위가 달라 기록 키도 새로 시작). 여기 폴더는
이정표 리다이렉트만 남아 있고, 명예의 전당 집계에서도 빠졌습니다.

`fillfridge`는 장 본 것들을 끌어서 냉장고에 딱 맞게 넣는 배치 퍼즐입니다.
냉장고 빈칸을 조각(1×1~2×2)으로 분할해 아이템을 만드는 역방향 생성이라
항상 완벽히 채울 수 있고, 넣은 물건은 다시 눌러 빼낼 수 있습니다.

`hall-of-fame`은 아홉 개 게임 개인 최고 스테이지의 **총합** 랭킹입니다.
닉네임으로 한 번 등록하면(`/_puzzletotal`, 방문자 쿠키 기준) 이후 어떤
게임에서든 개인 기록이 갱신될 때 서버가 총합을 자동 반영합니다. 랭킹
조회는 공개, 상위 50명 노출.

## 양산 규칙

- 토이 관례는 slop과 동일: 폴더 하나 = 게임 하나, 바닐라 단일 `index.html`,
  첫 이모지 = 카드 아이콘, share.js + `blWeekly`/`blWeeklyReport` + `_infra/records.js`
  `GAMES` 등록.
- 공통 컨셉: 따뜻한 톤(#f6ead8/#1a1626), ui-monospace, "광고는 가짜지만 이건
  진짜임" 자기소개, 실패 문구는 광고 드립.
- 기록은 전부 `클리어 스테이지 최대`로 통일해 명예의 전당에서 비교 가능하게.
- 스테이지는 무한(순환 또는 절차 생성)으로, 뒤로 갈수록 빡빡해지게.
- 생성형은 `genTuned()`에서 난이도 목표(`targetD`)와 **인접 스테이지
  유사도 페널티**(구조 지문 자카드 × 30)를 함께 최소화해 "또 같은 판"을
  막는다. 지문·검증은 `DIFFICULTY.md` 참고, 값은 `window.blSimAt(s)`.
- 모든 게임에 `<script defer src="/_shared/like.js"></script>`로 추천(👍) 버튼을
  단다. 우하단 유틸 독에 붙고, 방문자당 게임별 1회, 집계는 서버(RecordsDO의
  `/_like`)에 쌓여 어떤 게임이 인기인지 보인다.

## 후보 목록 (2026-07 리서치, 우선순위순)

가짜 광고 단골 장르 중 아직 없는 것들. 기준: ① "아 그 광고!" 인지도
② 바닐라 단일 HTML 구현성 ③ 시드 고정 + 풀이 보장 생성 가능 여부.

1. **파이프 물 연결** — 타일을 회전시켜 수도관 잇기. 경로 먼저 깔고
   돌려놓는 역방향 생성으로 풀이 보장. 클래식.
2. **잔디 깎기** (Mow it) — 잔디를 끌어서 싹 미는 힐링형. 커버리지
   판정만 있으면 되지만 퍼즐성이 얕아 후순위.

보류(구현 비용 큼): 브릿지 레이스류(유사 3D 러너), 밧줄 잘라 구출
(로프 물리), 모래 파서 물 흘리기(입자 시뮬 — 언젠가 도전 과제로).
제외: 영웅 레버 구출(pullpin과 사실상 동일), 숫자 병합 대전(2048·
gaterunner와 중복), ASMR 정리류(게임성 없음).
