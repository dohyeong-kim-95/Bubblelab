# trip — 여행 계획·예산

trip.bubblelab.dev. 혼자 쓰는 여행 계획·예산 화면이다. **비공개 서브도메인**
(`_infra/build.mjs`의 `CONFIDENTIAL_SUBDOMAINS`) — 랜딩·풀다운·검색 어디에도 나오지
않고 주소를 직접 쳐야 들어온다. 토이가 아니라서 토이 관례(share.js, 주간 기록)는
적용하지 않는다.

**로그인은 없다.** estate·lab과 같은 방식이라 주소를 아는 사람은 그냥 들어온다.
다만 워커가 `no-store` + `X-Robots-Tag: noindex, nofollow`를 붙이고
(`_infra/worker.js`) 방문 집계에서도 빠진다 — 워커의 페이지 집계와
`_shared/engagement.js`의 체류 집계 **양쪽에서** 빼서, 화면이 서버로 보내는 요청이
아예 없다(자기 정적 파일 둘 말고는 네트워크를 쓰지 않는다). 남에게 보이면 곤란한
것(예약번호, 카드번호, 여권번호)은 적지 않는다.

## 저장 위치 — 서버가 없다

기록은 **브라우저 localStorage(`bl-trip-v1`)에만** 있다. 서버로 보내지 않고 DO도
R2도 쓰지 않는다. 그래서:

- 기기를 옮기거나 브라우저 데이터를 지우면 사라진다 → 하단 **⬇ 내보내기**로 JSON을
  받아 두고, 새 기기에서 **⬆ 가져오기**로 넣는다(가져오기는 **덮어쓰기**다).
- 폰과 PC가 자동으로 동기화되지 않는다. 한쪽을 원본으로 정해 두는 게 편하다.

## 화면

- **일정 탭** — 여행 기간이 날짜 카드로 펼쳐진다. 항목은 시간·내용·분류·금액·
  상태(계획/예약/결제)·메모. 항목을 누르면 그 자리에서 편집되고, 추가 후에는 빈 폼이
  다시 열려 연달아 넣을 수 있다.
  - 날짜를 비워 두면 맨 아래 **"날짜 미정"** 카드로 모인다(항공권처럼 금액만 먼저
    잡아 두는 경우). 기간 밖으로 밀려난 항목도 여기로 내려올 뿐 지워지지 않는다.
  - **총액에는 날짜 미정·기간 밖 항목도 들어간다** — 빠지면 예산이 거짓말이 된다.
- **예산 탭** — 분류(항공·숙소·교통·식비·관광·쇼핑·기타)마다 예산을 넣으면 계획액과
  비교해 막대·초과액이 나온다. 합계 줄에 1인당·하루당이 같이 뜬다.
- 통계 줄: D-day · 계획 총액 · 예산 잔액 · 결제 완료.

## 금액과 환율

금액은 **항상 원(KRW) 정수로 집계**한다. 항목은 원/현지통화 중 하나로 입력하고,
현지통화는 여행마다 하나뿐인 환율(⚙️ 설정, 현지 1단위 = ?원)로 환산된다. 항목마다
환율을 두지 않는 건 의도한 것 — 환율을 고쳤을 때 과거 항목이 따라오지 않으면 계획
단계에서 더 헷갈린다. 계획용 어림값이지 회계 장부가 아니다.

`1인당 금액` 체크를 켜면 그 항목만 인원수만큼 곱해진다(식비·입장료).

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 전부 (바닐라, 의존성 없음) |
| `budget.js` | 순수 계산 — 환산·집계·기간·저장본 정규화 |

**계산은 `budget.js` 밖으로 새지 않게 한다.** 화면과 `_infra/trip.test.mjs`가 같은
모듈을 쓰기 때문에, 합계를 index.html 안에서 따로 더하기 시작하면 테스트가 못 보고
언젠가 두 숫자가 어긋난다.

저장본은 읽을 때 `normalizeStore`가 **거절하지 않고 고친다** — 남의 파일이 아니라 내
옛 저장본을 여는 쪽이라, 모르는 필드는 버리고 이상한 값은 기본값으로 끌어내린다
(환율 0 → 1, 인원 0 → 1, 모르는 분류 → 기타). 거절하면 기록만 잃는다.

## 검증

```bash
node --test _infra/trip.test.mjs        # 계산 단위 테스트
node _infra/build.mjs                   # CONFIDENTIAL 등록 확인 (누락이면 여기서 실패)
npx wrangler@4 dev --local --local-upstream localhost   # http://localhost:8787/trip/
```

라이브 검증은 `node _infra/verify-prod.mjs --only site:trip`(폴더가 있으면 프로브가
자동 생성된다 — 게이트가 없으므로 200 + HTML을 기대한다). 모바일 스모크 대상이라
`_infra/e2e/smoke.spec.mjs`의 `SCREENS`에도 `/trip/`이 있다.
