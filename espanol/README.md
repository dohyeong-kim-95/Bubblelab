# espanol — 영화 한 편으로 스페인어

`espanol.bubblelab.dev`. 스페인 영화 **El buen patrón**(굿 보스, 2021)을 반복해 보면서
스페인어를 알아듣게 되는 것을 목표로 만든 개인 학습장. 사용자는 완전 초급(아는 말이
`español`·`hablar` 정도)이라는 전제로 쓰였다.

**토이가 아니라 자체 index.html을 가진 서비스다** — 토이 관례(`share.js`, 주간 기록,
카드 카테고리 홈 자동 생성)를 적용하지 않는다. 공용 홈 버튼(`_shared/home.js`)도
주입되지 않으므로 각 페이지가 상단 내비를 직접 들고 있다. 반면 랜딩 검색 색인은
하위 폴더를 자동으로 긁어가므로, 새 페이지를 만들면 `<title>`을 한국어로 짓고
**첫 이모지를 변이 선택자 없는 것으로** 고른다(빌드가 파일의 첫 이모지를 카드
아이콘으로 뽑는다 — `🗣️`처럼 VS16이 붙은 것은 반쪽만 잡힌다).

## 구조

```
espanol/
  index.html        홈 — 학습 순서, 오늘의 다섯 낱말, 진행 상황, 영화 보는 방법
  style.css         공용 스타일 (모든 페이지가 이 하나만 읽는다)
  app.js            공용 모듈 — 읽어주기 / 저장소 / 훈련 덱 / 복습 일정
  data/words.js     낱말 데이터 (7묶음, 약 240개)
  data/chunks.js    영화에 계속 나오는 짧은 덩어리 (6묶음, 약 60개)
  sounds/           발음 — 읽는 규칙, 한국인이 놓치는 네 가지, 강세
  ear/              귀 트이기 — vale·claro·venga… 뜻보다 "언제 나오나"
  words/            단어장 — 검색·묶음 필터·⭐(훈련 우선)
  grammar/          최소 문법 13장 — 어미로 사람 알아내기, tú/usted, 과거 알아듣기
  drill/            훈련 — 듣고 맞히기 / 뜻 떠올리기 / 받아쓰기
  log/              시청 일지 — 들린 표현 수집(→ 훈련 카드), 백업 내보내기·가져오기
```

`data/` 에는 `index.html` 이 없어서 랜딩 검색 색인에 카드로 잡히지 않는다.

## 서버가 없다

전부 정적 파일이다. 진도·별표·일지는 `localStorage`에 `bl-es-` 접두사로만 저장된다
(`app.js`의 `KEYS`). 기기를 옮기려면 일지 페이지의 내보내기/가져오기를 쓴다.
새 저장 키를 늘릴 때는 `KEYS`에 넣어야 `BACKUP_KEYS`(내보내기 대상)에 자동으로 포함된다.

## 소리

읽어주기는 브라우저 내장 음성(`_shared/tts.js`)이다. API 키도, 서버 왕복도 없다.
페이지마다 `<head>`에서 **tts.js보다 먼저** 설정을 심는다:

```html
<script>window.blTTSConfig = { lang: "es-ES", dock: false, rate: 0.9 };</script>
<script defer src="/_shared/tts.js"></script>
```

`dock: false` — 공용 독의 🔊 버튼(페이지 전체 읽기)은 쓰지 않고, 항목마다 붙는
`app.js`의 `sayButton()`을 쓴다. 본문 속 예시는 `data-say` 속성만 달면
`mountSayButtons()`가 버튼을 꽂아 준다.

**스페인어 음성이 없는 기기가 있다.** `warnIfNoVoice()`가 목소리 목록이 준비된 뒤에
판정해서 안내 문구를 넣는다 — 조용히 실패하게 두면 사용자는 고장으로 받아들인다.

## 내용을 고칠 때

- 낱말·덩어리를 늘리려면 `data/*.js` 한 줄만 추가한다. 단어장·훈련·오늘의 낱말·홈 통계가
  모두 이 파일을 읽으므로 다른 곳은 손댈 필요가 없다.
- **훈련 카드 id는 스페인어 표기에서 나온다**(`w:jefe`). 순번이 아니라 내용 기반이라,
  중간에 항목을 끼워 넣어도 기존 복습 기록이 다른 카드로 밀리지 않는다.
  반대로 **기존 항목의 `es` 를 고치면 그 카드의 학습 기록은 새 카드로 리셋된다.**
- 비속어 항목은 `rude: true` 로 표시한다. 기본으로 감춰지고, 귀 트이기 페이지에서
  켜면 훈련 덱에도 함께 들어간다(같은 `bl-es-rude` 값을 본다).

## 저작권

**영화 대사를 옮겨 싣지 않는다.** 모든 예문은 같은 상황에서 쓸 수 있게 새로 쓴 문장이다.
작품 제목·감독·배경 설명 같은 사실 정보는 쓰지만, 자막·대본 텍스트는 넣지 않는다.
내용을 늘릴 때도 이 선을 지킬 것.

## 검증

```bash
node _infra/build.mjs        # 랜딩 카드 검사 포함 (퍼블릭 서브도메인은 카드 필수)
npm test
npm run test:e2e             # espanol 홈·훈련이 스모크 대상에 들어 있다
npx wrangler@4 dev --local --local-upstream localhost
# http://localhost:8787/espanol/
```
