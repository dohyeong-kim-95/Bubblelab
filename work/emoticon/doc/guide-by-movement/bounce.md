# bounce — 통통튀기

**상태: · 미착수.** 채널은 **rig** — 전신 세로 이동이라
[`nod.md`](nod.md)가 아홉 번 막힌 그 벽과 같은 종류다.

## 들어가기 전에 알아야 할 것

**Gemini 이미지 편집은 매 호출 피사체를 캔버스에 다시 배치·정규화한다.**
그래서 "캐릭터가 위로 뜬다" 같은 **전신 이동 지시는 지워진다.** nod에서
아홉 번 확인됐고, 텍스트뿐 아니라 **배치도 이미지를 보여줘도** 되돌린다
(`nod.md` §5, `lesson_learned.md` §45~47).

→ **점프의 높이는 코드가 만들어야 한다.** 프롬프트로 시도하면 nod를 반복한다.

## 설계 초안 (미검증)

1. **모델에게는 표정과 스쿼시만 시킨다** — 검증된 채널.
   - 웅크림(앤티시페이션): 눈 감김 + 몸 세로 0.9배·가로 1.08배(부피 보존)
   - 최고점: 눈 크게 + 몸 세로 1.06배·가로 0.95배
   - 착지: 눈 감김 + 웅크림과 같은 스쿼시
2. **세로 이동은 리그가 넣는다** — 프레임별 평행이동. `alignFrames`의 반대
   동작이므로 **`cut.json`에 `"anchor": "none"`을 반드시 넣어야 한다**
   (안 넣으면 build가 점프를 정렬로 지운다).
3. 타이밍은 12원칙대로 **위에서 느리고 아래에서 빠르게**(ease out/in) —
   최고점 근처에 프레임을 몰아준다.

## 아직 없는 것

- 세로 이동을 넣는 리그 함수. `emoticon-rig.mjs`에는 `nodRig`(얼굴 내리기)만
  있고 전신 평행이동은 없다. `alignFrames`의 이동 코드를 재사용하면 된다.
- `anchor: "none"` 경로는 build에 구현돼 있으나 **실사용 검증 전이다.**
