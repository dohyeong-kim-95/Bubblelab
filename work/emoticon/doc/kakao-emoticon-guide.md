# 카카오 이모티콘 가이드

카카오 이모티콘 스튜디오 제안·납품 규격과 구성 규칙. LINE은
[`line-emoticon-guide.md`](line-emoticon-guide.md).

> **주의**: 규격은 바뀐다. 제안 직전에 <https://emoticonstudio.kakao.com>을
> 직접 열어 최종 확인할 것. 이 문서는 2026-07~08 리서치 시점 기준이다.

## 1. 정책 — 전략을 결정하는 제약 (먼저 읽을 것)

**생성형 AI 이모티콘 입점이 사실상 막혀 있다.** 2023-09부터 잠정 제한됐고
2025-04 언론 확인 시점에도 "정책 변화 없음", 해제 보도는 2026-07 조사
시점까지 없다.

→ AI 산출물로 카카오 제안은 미승인 리스크가 크다. 카카오 트랙은
**(a) 정책 해제 대기** 또는 **(b) 손그림 원화 + 리깅(AI 미사용) 워크플로**
중 택일이며, **현실적 1순위 출구는 LINE이다.**

## 2. 규격

| | 제안 단계 | 승인 후 납품 |
|---|---|---|
| 형식 | 애니 GIF 3종(**흰 배경**) + 정지 PNG 21종(투명) | **WEBP** — 반드시 카카오 공식 [WebP 애니메이터](https://emoticonstudio.kakao.com/webp-animator)로 변환 |
| 개수 | 총 24종 | 24종 전부 애니메이션화 |
| 크기 | 360×360px | 360×360px |
| 프레임 | GIF 24프레임 이하 | ≤24프레임, 프레임당 0.05~2.0초 |
| 재생 | — | 빈 프레임 금지 |
| 용량 | GIF ≤2MB, PNG ≤150KB | — |

큰 이모티콘은 16종(PNG 13 + GIF 3).

우리 `master-2s` 프로필이 이 규격을 강제한다 — 360², 2~24프레임,
1.8~2.2초, 프레임당 0.05~2.0초.

## 3. 세트 구성 규칙 — 여기서 떨어진다

승인율은 비공식 추정 **3~5%**(경쟁률 20~30:1). **규격 충족은 출발선이고,
떨어지는 건 캐릭터 매력·감정 전달·실사용성이다.**

- **80% 이상을 일상 대화 감정으로 채운다** — 인사·거절·공감·분노처럼 대화에서
  실제로 자주 쓰이는 것. 나머지 20%가 캐릭터 개성("병맛"·독특한 행동).
- **세트 안에서 감정·상황이 중복되면 안 된다.** 각 컷은 직관적으로 하나의
  감정·상황을 읽혀야 한다.
- **→ 예쁜 표정 24개가 아니라 "쓸 자리가 다른" 24개여야 한다.** "기쁨"을 세
  가지 버전으로 만드는 건 세 칸을 낭비하는 것이다.
- **AI 티 제거**: 프레임 간 디테일 드리프트(장신구가 생겼다 없어지는 것)는
  탈락 사유급이다. 우리 부품 게이트가 이걸 겨냥한다.
- **루프의 완성도**: 튀는 루프 하나가 팩 전체 인상을 깎는다.

## 4. 기간·수익

- 제안 무료, 심사 2~4주. 승인 후 검수 왕복으로 출시까지 2~5개월.
- 수익 배분은 **판매가의 약 35%**가 작가 몫(앱마켓 30% 차감 후 5:5 안팎,
  비공식).
