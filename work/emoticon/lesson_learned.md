# lesson_learned — 파일럿에서 실측으로 배운 것

2026-07-31 파일럿(rabbit 캐릭터, 시트 1 + 컷 2회 + 실패 1프레임, 총 ≈$1)에서
배운 것만 적는다. 방법론 전반은 `SKILL.md`, 완료 조건은 `goal.md`.
**다음 반복 전에 이 파일부터 읽고, 반복이 끝나면 여기에 추가한다.**

## 인프라에서 배운 것

1. **Cloudflare Workers에서 Gemini 이미지 생성은 지역 차단에 걸린다.**
   `FAILED_PRECONDITION: User location is not supported` — 워커의 이그레스
   IP가 미지원 지역으로 geolocate 되는 경우이며 우리가 제어할 수 없다.
   같은 키로 팟캐스트(텍스트·TTS, cron 실행)는 통과한다 — 실행 시점의
   데이터센터가 다르고 이미지 모델의 지역 제한이 더 엄격하다.
   → **생성 실행처는 GitHub Actions 러너(미국 IP)가 기본.** 잡 파일
   (`_src/emoticon/job.json`) 커밋으로 트리거한다.
2. **Worker secret은 어디서도 읽어올 수 없다** (write-only). 다른 실행 환경
   (Actions·로컬)에서 쓰려면 같은 값을 그 환경의 secret으로 한 번 더
   등록해야 한다. 이건 우회가 아니라 구조다.
3. **세션의 GitHub 토큰으로는 workflow_dispatch를 못 부른다**(actions:write
   없음). push 트리거(잡 파일 패턴)가 에이전트 친화적 우회다.
4. **산출물을 리포에 커밋하는 구조가 반복 속도를 결정한다.** 에이전트가
   pull → 이미지 확인 → 프롬프트 수정 → 재잡 커밋의 루프를 사람 개입 없이
   돈다. 실패해도 부분 산출물(frames-raw)을 커밋해야 원인을 이미지로 볼 수
   있다 (`if: always()`).

## 생성 품질에서 배운 것

5. **배경 색 지시는 레퍼런스 이미지에 진다.** "초록 배경(#00FF00)"이라고
   써도 흰 배경 시트를 레퍼런스로 주면 흰 배경으로 그린다. 싸우지 말 것 —
   흰 배경으로 생성하고 누끼는 모서리 색 자동 판별(autoCutout: 초록이면
   크로마키, 흰색이면 sticker-pack의 플러드필)로 처리한다.
6. **캐릭터 일관성은 생각보다 잘 나온다.** 시트 1장 + 첫 프레임 + 직전
   프레임을 레퍼런스로 주면 12프레임 전부 같은 캐릭터가 유지됐다(귀·볼터치·
   선 굵기·비율). goal.md 기준 1은 현재 전략으로 근접했다.
7. **시간적 연속성이 진짜 병목이다.** "프레임 i/N" 지시만으로는 모델이
   프레임마다 독립적인 포즈를 그린다(팔이 좌우로 바뀌고 크기가 출렁임 —
   1차 루프 diff 34%, 재생하면 보일링).
8. **포즈 스크립트(프레임당 포즈 문장 1개)가 즉효였다.** 동작 진행을
   "2번: 오른팔 어깨 높이, 3번: 머리 위로 쭉…"으로 고정하니 동작 아크가
   생기고 루프 diff 34→21%. `cut --poses` / 잡 파일 `poses` 배열.
9. **"오른팔" 같은 좌우 표현은 캐릭터 기준/화면 기준이 섞인다.** 프레임마다
   해석이 달라져 드는 팔이 좌우로 오갔다. → 포즈 문장은 **"화면 기준
   오른쪽"**처럼 시점을 명시할 것. (다음 반복에서 검증 예정)
10. **12fps·12프레임은 아직 인접 프레임 변화가 크다**(최대 diff 32%).
    다음 실험: 8프레임 @8fps — 변화 폭과 비용을 같이 줄인다. 사람 애니메이션
    기법(2s 작화 등)은 `animation-techniques.md` 참고.
11. **모션 라인(속도선)은 지시 없이도 그려 넣는데, 이모티콘에선 오히려
    자연스럽다.** 금지하지 않는다. 단 프레임 간 위치가 널뛰면 소음이 된다.

## 비용·시간 감각 (실측)

- 시트 1장 ≈ $0.04, 12프레임 컷 1개 ≈ $0.5, Actions 잡 1회 ≈ 4~5분.
- 실패 비용은 작다(프레임 1장 $0.04에서 멈춤). 실패를 두려워하지 말고
  검증을 앞단에 둘 것.
- 32컷 북극성 기준 순수 생성비는 ≈$16, 재시도 2배 잡아도 ≈$30 — 예산은
  문제가 아니고 **반복당 4~5분의 시간이 실질 제약**이다. 포즈 스크립트를
  먼저 다듬고 나서 프레임을 늘리는 순서가 싸다.
