신규 의뢰

프로젝트 개요를 보내주시면 수행 가능 여부와 함께 범위·일정·견적을 회신드립니다.

Services

  • 브랜드 웹사이트 · 제품 랜딩 페이지
  • 인터랙티브 웹 콘텐츠 (스크롤 연출 · 웹 게임 · 캠페인 페이지)
  • 소규모 웹 서비스 · 내부 도구 (예약·조회·기록 등 단일 목적 서비스)
  • 기존 웹사이트 개선 (성능 · 모바일 대응 · 디자인 리뉴얼)

Briefing

문의 시 아래 항목이 포함되면 정확한 회신이 가능합니다.

  • 프로젝트 목적과 요구사항 개요
  • 참고 자료 (유사 사이트 링크, 보유 브랜드 에셋 등)
  • 희망 일정
  • 예산 범위 (미정이어도 무방)

Process

  1. 문의 접수 — 영업일 기준 1~2일 내 회신
  2. 협의 — 범위·일정·견적 확정 후 계약
  3. 제작 — 전용 미리보기 환경(의뢰 ID 발급)에서 시안 검토·피드백
  4. 인계 — 검수 완료 후 소스 코드 포함 산출물 전체 이관
