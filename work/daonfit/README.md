# daonfit — 다온핏 브랜드 랜딩페이지 (외주 시안)

상태: **작업 중**. work.bubblelab.dev/daonfit 에서 비밀번호 입력 후 확인.

컨셉이 전면 교체되었습니다. 이전의 쇼핑몰형 시안(상품 상세·리뷰·문의 Q&A·admin)은
삭제하고, 클라이언트가 확정한 **브랜드 스토리 랜딩 단일 페이지**로 재구성했습니다.
구매·문의 도선은 네이버 스마트스토어와 인스타그램 DM 링크 두 개뿐입니다.

3D프린팅 생활 맞춤 소품 브랜드 "다온핏"(스마트스토어 `samyong_2`, 인스타그램
`@daonfit`)의 홈페이지이며, 이 사이트는 서버에 아무것도 저장하지 않습니다.

- 구성: 스크롤 연동 로고 조립 인트로(받침→세 갈래→점, 인라인 SVG) → 이름의 뜻
  (다온/핏) → 만드는 방식 4단계 → 만드는 사람 → 스토어·인스타 링크 CTA.
  `prefers-reduced-motion`이면 인트로를 완성 상태로 정지 렌더합니다.
- 파일은 `index.html` 하나(스타일·스크립트 인라인). 웹폰트는 Google Fonts
  (Gowun Batang, Gothic A1)를 사용합니다(장애 시 시스템 폰트로 대체).
- 기획안 결정 사항은 모두 권장안으로 확정: 상단 "스토어 가기"는 페이지 하단
  CTA로 앵커 이동, 문의 게시판은 두지 않음(문의는 인스타 DM·스마트스토어로
  일원화), 링크 미리보기용 OG 이미지(`_work_assets/og.png`, 1200×630)와
  메타 태그 반영. **`og:image` URL은 정식 오픈 시 실제 도메인으로 교체.**
- **mock 데이터(인계 전 실제 정보로 교체)**: 대표 사진은 실루엣 아바타(SVG),
  footer의 사업자등록번호(000-00-00000)·통신판매업신고번호는 가짜 값입니다.
  "만드는 사람" 인용문·태그도 임시 문구입니다. 위치는 index.html의
  `mock` 주석 참고.
- `_work_assets/`의 로고 권리는 다온핏에 있습니다. 무단 사용 금지.
  (`logo.png`는 파비콘용, `og.png`는 로고 기반 자체 제작. 임시 상품 사진은
  삭제했습니다.)
- 이전 시안이 쓰던 리뷰 동기화 백엔드(`_infra/reviews.js`의 `WorkReviewsDO`,
  worker의 `/_workreviews/` 라우트·cron 등록 `WORK_REVIEW_PROJECTS`)와
  `/_workqna/daonfit` 문의 보드는 이 페이지에서 더 이상 쓰지 않습니다.
  당장은 무해한 유휴 코드로 남겨두었고, 인계·서비스 종료 시 정리하면 됩니다.
- 자체 완결: 이 폴더는 `_shared` 등 리포 공용 리소스에 의존하지 않고 폴더 내부
  리소스만으로 구동됩니다. 인계 시 이 폴더를 통째로 전달하고 리포에서 삭제합니다.
