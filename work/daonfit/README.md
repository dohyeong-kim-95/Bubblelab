# daonfit — 다온핏 브랜드 랜딩페이지 (외주 시안)

상태: **작업 중**. work.bubblelab.dev/daonfit 에서 비밀번호 입력 후 확인.

컨셉이 전면 교체되었습니다. 이전의 쇼핑몰형 시안(상품 상세·리뷰·문의 Q&A·admin)은
삭제하고, 클라이언트가 확정한 **브랜드 스토리 랜딩 단일 페이지**로 재구성했습니다.
구매·문의 도선은 네이버 스마트스토어와 인스타그램 DM 링크 두 개뿐입니다.

3D프린팅 생활 맞춤 소품 브랜드 "다온핏"(스마트스토어 `samyong_2`, 인스타그램
`@daonfit`)의 홈페이지이며, 이 사이트는 서버에 아무것도 저장하지 않습니다.

- 구성: 스크롤 연동 로고 조립 인트로(받침→세 갈래→점, 인라인 SVG) → 이름의 뜻
  (다온/핏) → 만드는 방식 4단계 → 스토어·인스타 링크 CTA.
  ("만드는 사람" 소개 섹션은 클라이언트 요청으로 보류 — 재추가 여부 추후 결정.)
  `prefers-reduced-motion`이면 인트로를 완성 상태로 정지 렌더합니다.
- 인트로 연출(2~4차 피드백 반영): 세 갈래가 과장된 사인 아치를 그리며 크게
  휘돌아 들어와 **받침 → 왼팔 → 가운데 → 오른팔 순서로** 우주선 착륙 커브
  (quart-out, 빠른 접근 → 긴 감속 → 오버슈트 없는 터치다운)로 앉는다.
  받침·갈래는 **착지 직후 눌렸다 튀는 스쿼시 반동**(감쇠 진동, 결합점 기준 —
  '꼭 맞는' 맞물림)을 한 번씩 하고, 착지마다 그 자리에서 임팩트 링(파문)이
  퍼진다. 마지막 오른팔이 앉은 직후 "팡!" 섬광과 14개 스파크 버스트, 점 셋은
  찌그러졌다 복원되는 팝으로 정착(p 0.445 이전에 잔여 연출 소멸, 이후
  워드마크·문장 전환).
- 파일은 `index.html` 하나(스타일·스크립트 인라인). 웹폰트는 **Wanted Sans
  Variable 셀프호스팅**(`_work_assets/fonts/`, OFL — 로고의 두껍고 둥근 맺음과
  결을 맞춘 단일 패밀리로 통일, 옛 명조 강조는 무게 800으로 대체). unicode-range
  분할(woff2 92개)이라 실제 쓰인 글자 분량만 내려받습니다(장애 시 시스템 폰트로
  대체).
- 인트로는 **스크럽 방식(5차 피드백으로 페이징 폐기)**: 스크롤 위치가 곧 재생
  바다. 조금 내리면 조각 하나가 자리잡고, 멈추면 애니메이션도 그 자리에 멈추고,
  올리면 거꾸로 흩어진다(횟수 제한·스냅·휠 가로채기·관성 잠금 전부 없음 —
  네이티브 자유 스크롤). 조각이 하나씩 순서대로 모이는 순차 조립이라 중간에
  멈춘 화면도 "한 조각이 막 자리잡은" 의도된 장면으로 성립한다. 무대는 300vh,
  조립은 p 0~0.445, 워드마크 부상 0.48~0.73, 문장 전환은 pulse 구간으로 배치.
  reduced-motion에서는 완성 상태 정지 렌더.
- 전환 UX 보강(Search Engine Watch "11 quick UX tips" 대조 반영): 첫 화면부터
  첫 문장이 보이도록 인트로 타이밍 조정 + 스크롤 길이 440vh→300vh 압축,
  인트로가 끝나면 하단 고정 CTA 바(구매 만족도 ★5.0 + 스토어 버튼) 노출
  (하단 CTA 섹션이 보이면 자동 숨김), 스마트스토어 아웃링크에 UTM 파라미터
  (`utm_source=daonfit-landing`, 본문/`brand`·dock/`brand-dock` 구분), 인트로
  높이는 `100dvh`(iOS·안드로이드 주소창 대응, `100vh` 폴백), CTA 위 신뢰
  문구 한 줄.
- 기획안 결정 사항: 상단 "스토어 가기"는 스마트스토어로 **바로 이동**(5차
  피드백, UTM `brand-topbar`), 문의 게시판은 두지 않음(문의는 인스타 DM·
  스마트스토어로 일원화), 링크 미리보기용 OG 이미지(`_work_assets/og.png`,
  1200×630)와 메타 태그 반영. **`og:image` URL은 정식 오픈 시 실제 도메인으로
  교체.**
- 본문 문구는 5차 피드백에서 클라이언트가 보낸 원고로 전면 교체(해요체, 생활
  용품 브랜드 시점 — 자동차 예시 제거). footer의 사업자등록번호·통신판매업신고
  줄은 실제 번호 확정 전까지 **표기하지 않음**(index.html 주석 위치에 추가).
- `_work_assets/`의 로고 권리는 다온핏에 있습니다. 무단 사용 금지.
  (`logo.png`는 파비콘용, `og.png`는 로고 기반 자체 제작. 임시 상품 사진은
  삭제했습니다.)
- 이전 시안이 쓰던 리뷰 동기화 백엔드(`_infra/reviews.js`의 `WorkReviewsDO`,
  worker의 `/_workreviews/` 라우트·cron 등록 `WORK_REVIEW_PROJECTS`)와
  `/_workqna/daonfit` 문의 보드는 이 페이지에서 더 이상 쓰지 않습니다.
  당장은 무해한 유휴 코드로 남겨두었고, 인계·서비스 종료 시 정리하면 됩니다.
- 자체 완결: 이 폴더는 `_shared` 등 리포 공용 리소스에 의존하지 않고 폴더 내부
  리소스만으로 구동됩니다. 인계 시 이 폴더를 통째로 전달하고 리포에서 삭제합니다.
