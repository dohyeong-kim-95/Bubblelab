웹 게임

Fruit Merge

같은 과일을 합쳐 더 큰 과일로 키우는 물리 퍼즐 게임.

라이브로 열기 →

Overview

떨어뜨린 과일이 굴러가고 부딪히는 물리 시뮬레이션 위에서, 같은 과일끼리 닿으면 합쳐지는 규칙으로 진행됩니다. 프레임워크 없이 Canvas와 바닐라 JavaScript만으로 구현했습니다.

Notes

  • 자체 물리 시뮬레이션 — 중력·충돌·병합 판정을 직접 구현
  • 모바일 터치 조작 — 이동·놓기 두 동작으로 단순화
  • 주간 신기록 보드 — 서버 검증을 거치는 기록 제출
