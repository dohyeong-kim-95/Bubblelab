아발론 온라인

보드게임 아발론을 5~10인이 브라우저만으로 즐기는 실시간 멀티플레이어 서비스.

Overview

방 개설부터 역할 배정, 원정대 구성과 투표, 암살 단계까지 전체 게임 진행을 온라인으로 옮겼습니다. 앱 설치 없이 링크 공유만으로 시작하고, 접속이 끊겨도 재접속하면 진행 중인 판으로 복구됩니다.

Notes

  • 자체 실시간 서버 — Cloudflare Durable Object 기반 — 외부 서비스 의존 없음
  • 동시 접속 상태 동기화 — 경로 트리 구독 프로토콜, 끊김 감지·재접속 복구
  • 모바일 우선 UI — 게임 진행 단계별 화면 전환
