# /paper — 논문 하나를 붙들고 이해될 때까지 판다

`life/papers` 에 글이 남는 **유일한 길**이다. 디스코드 봇은 여기 쓰지 못한다 —
저기는 초록만 보고 거르는 자리고, 여기 남는 것은 **내가 직접 이해한 논문**이다.
기계 요약을 저 목록에 쌓으면 다이제스트와 다를 게 없어진다.

```
/paper 2608.19808     번호로 시작
/paper                오늘 다이제스트에서 고르게 해준다
/paper 정리           지금 붙들고 있는 것을 끝내고 life/papers 에 남긴다
```

## ① 시작 — 전문을 읽는다

번호가 없으면 오늘 것을 보여주고 고르게 한다:

```bash
curl -s https://life.bubblelab.dev/_papers/latest
```

번호가 정해지면 **PDF 전문**을 받는다. 초록으로 때우지 않는다 — 초록만 볼 거면
디스코드에서 이미 봤다.

```bash
curl -sL "https://arxiv.org/pdf/<번호>" -o "$CLAUDE_JOB_DIR/tmp/<번호>.pdf" \
  || curl -sL "https://arxiv.org/pdf/<번호>" -o /tmp/<번호>.pdf
```

Read 도구로 읽는다(PDF 를 직접 읽는다. 10쪽이 넘으면 `pages` 로 나눠 받는다).
**전부 읽는다** — 실험 설정과 부록에 쓸 만한 게 있고, 초록에는 그게 없다.

읽고 나서 이렇게 연다:

- 한 문단으로 무엇을 한 논문인지
- **내 문제와 부딪히는 지점 두세 개** (순서형 3x10^14 조합 공간 · 다목적 · 800회 예산)
- "여기부터 물어보면 된다" 는 자리 세 개를 제안

그다음은 **묻는 대로 답한다.** 이해될 때까지 붙어 있는 게 이 명령의 목적이다.
모르면 모른다고 하고 논문의 어디를 같이 보면 되는지 말한다. 지어내지 않는다.

## ② 끝 — 이해한 것만 남긴다

`/paper 정리` 라고 하거나 대화가 마무리되면 남긴다. **사용자가 실제로 물은 것과
스스로 내린 결론이 들어가야 한다** — 그게 이 글을 기계 요약과 가르는 부분이다.
물은 게 하나도 없으면 남기지 말고 "아직 붙들고 있는 중" 이라고 한다.

일곱 항목은 이대로 쓴다(`REVIEW_FIELDS` 와 같아야 한다. 바꾸면 테스트가 잡는다):

무엇을 한 논문인가 · 핵심 방법 · 전제와 가정 · 실험 설계 · 내 문제 적용 ·
따라 해볼 것 · 한계와 의심

```bash
set -a && . ~/.bubblelab/papers.env && set +a
curl -s -X POST https://life.bubblelab.dev/_papers/reviews \
  -H "Authorization: Bearer $PAPERS_SINK_SECRET" \
  -H "Content-Type: application/json" \
  -d @payload.json
```

`payload.json` 의 모양:

```json
{
  "paper":   { "id": "2608.19808", "title": "…", "link": "https://arxiv.org/abs/2608.19808",
               "published": "2026-08-20", "authors": ["…"] },
  "source":  "full",
  "review":  { "무엇을 한 논문인가": "…", "핵심 방법": "…" },
  "asked":   ["사용자가 실제로 물은 것을 그대로", "…"],
  "verdict": "사용자가 내린 결론. 대신 지어내지 말 것 — 애매하면 물어서 받는다."
}
```

- `source` 는 `full`(전문) 이나 `abstract`. **전문을 안 읽었으면 `full` 이라고 하지 않는다.**
  나중에 이 글을 얼마나 믿을지가 여기서 갈린다.
- `asked` 는 **사용자의 말**이다. 내가 던진 물음을 넣지 않는다.
- `verdict` 도 사용자의 것이다. 대화에서 분명히 나오지 않았으면 한 줄 물어서 받는다.

남긴 뒤 `https://life.bubblelab.dev/papers` 를 알려준다.

## 왜 봇이 아니라 여기인가

디스코드 봇은 `--allowed-tools ""` 로 돈다 — arXiv 초록이 프롬프트에 들어가는데
내가 없을 때 도는 물건이라 도구를 쥐여 줄 수 없다. PDF 를 받아 읽고 코드를
돌려 보는 일은 **사용자가 보고 있는 이 자리**에서만 안전하다.
