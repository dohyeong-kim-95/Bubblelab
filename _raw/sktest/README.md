# _raw/sktest — 내가 직접 구한 연습 자료를 두는 곳 (로컬 전용)

`sktest/workbook/`(PDF 연습실)에 올릴 **내 PDF**를 두는 자리다.

## 왜 여기인가

- 폴더 이름이 `_`로 시작해서 **배포되지 않는다**(`_infra/build.mjs`의 `isSite`).
  `sktest/` 안에 두면 `sktest.bubblelab.dev/…`로 그대로 서빙된다 — 배포 필터는
  README·CLAUDE·AGENTS만 걸러내고 나머지 파일은 전부 내보낸다.
- `.gitignore`가 이 폴더의 내용물을 커밋에서 제외한다(이 README만 추적).
  공개 저장소에 자료가 실려 나가지 않는다.

## 무엇을 두는가

내가 **정당하게 구한 것만** 둔다 — 구매한 문제집 PDF, 출판사가 공개한 미리보기,
공식 안내 자료, 직접 만든 연습지.

시중에 도는 "기출 복원" 파일은 두지 않는다. 그 자체가 시험 저작물의 무단
복제물이라 개인 소장도 회색이고, 저장소에 들어오는 순간 배포·배포이력까지 남는다.
`sktest/README.md`와 `COPYRIGHT_REMEDIATION_PLAN.md`가 같은 선을 긋고 있다.

## 쓰는 법

PDF 연습실은 **파일 경로를 읽지 않는다.** 브라우저 파일 선택창으로 고르면
그 바이트만 탭 안에서 열린다(업로드 경로 자체가 없다). 그래서 이 폴더는
"파일 선택창에서 항상 여기를 열면 된다"는 약속일 뿐, 코드가 참조하지 않는다.

1. 여기에 PDF를 둔다
2. https://sktest.bubblelab.dev/workbook/ → `PDF 선택 / 변경`
3. 문항 수·시간 고르고 시작, 끝나면 정답표를 붙여넣어 채점

정답표는 자료에 딸린 것을 직접 입력한다(1번부터 순서대로, 쉼표·공백·줄바꿈 아무거나).
