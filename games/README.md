## 새벽 두 시의 찻집 (`teahouse/`)

잠 못 드는 손님이 기억하는 "그 맛"을 단서로 찾아 차를 블렌딩하는 스토리 게임의 데모(네 번의 밤, 약 40분).
**원본은 이 리포가 아니다** — `~/Working_kdh/1_Projects/MOBILEGAME/game/` 에서 만들고 이 폴더로 통째로 복사한다
(여기서 직접 고치지 말 것. 다음 복사 때 덮인다). 기획·결정은 MOBILEGAME 의 `CLAUDE.md`·`docs/`.

| 항목 | 내용 |
| --- | --- |
| 그림 | 찻집은 코드로 그린 픽셀아트(160×144 캔버스). 인물 일러스트는 AI 이미지 생성 WebP(`art/`, 약 0.6MB, 게임 안 크레딧에 표기) |
| 음악 | 음표 데이터(`audio/songs.json`) + CC0 악기 샘플(VSCO2 CE·VCSL) 샘플러, 문 종소리만 CC BY 4.0, 빗소리는 제작자 녹음 (게임 안 크레딧에 표기) |
| 글꼴 | Galmuri11 (OFL, `fonts/`) |
| 저장 | localStorage `teahouse.save.v1`, 밤 단위. 주소 이전 대비 이어하기 코드(`TEA1.…`) |
| PWA | `manifest.webmanifest` + `sw.js`(범위 = 이 폴더, 버전 묶음 cache-first). `sw.js` 의 목록·버전은 MOBILEGAME 의 `npm run sw` 가 만든다 |
| 디자인 | 화면 전체가 놀이 화면(밤 픽셀아트)이라 둘레 UI 도 bubble.css 대신 게임 자체 스타일. 공용 독은 `<meta name="bl-dock" content="off">` 로 끔 |

나중에 `teahouse.bubblelab.dev` 로 독립할 수 있게 모든 경로는 상대경로다.

## 발판 리듬 (`stepcam/`)

정적 페이지 하나로 끝나는 1인용 리듬게임입니다. 서버·계정이 필요 없습니다.

| 파일 | 역할 |
| --- | --- |
| `vision.js` | 배경 차분 → 그림자 억제 → 열별 최하단 접지점 → 발 좌표 → 발판 칸 매핑 |
| `chart.js` | 곡 목록·채보 생성(씨앗 고정)·판정 창·점수 |
| `audio.js` | WebAudio 합성 (드럼·베이스 + 채보를 그대로 연주하는 멜로디) |

인식은 96×72로 줄인 프레임 위에서만 돌아 폰에서도 30 fps를 유지합니다. 카메라
영상은 기기 밖으로 나가지 않고, 카메라를 못 쓰는 환경을 위해 손가락 모드가 있습니다.
점수는 그 판에서만 쓰고 서버로 보내지 않습니다 — `games/`는 slop 토이와 달리
주간 신기록 보드를 붙이지 않습니다. 로직 테스트는
[`_infra/stepcam.test.mjs`](../_infra/stepcam.test.mjs).

실시간 멀티플레이 게임(야추·라이어 게임·아발론)과 그 서버(`/_rt`, `RealtimeDO`)는
2026-11-10 에 걷어냈습니다 — 사용자 인증과 방별 읽기·쓰기 권한이 없어 넉 달째 닫혀 있었고,
그동안 코드·테스트·빌드만 배포에 붙어 있었습니다. 소스는 git 이력에 있습니다
(`git log -- games/yacht games/liargame _infra/realtime.js _src/avalon`). 다시 만든다면
방 참가자별 세션과 방 단위 권한을 서버가 강제하는 것부터 시작합니다.

새 정적 게임은 이 폴더에 바로 추가할 수 있지만, 보통 `slop/`에서 먼저 검증한 뒤
승격합니다.
