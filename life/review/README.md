# 돌아보기 (life/review)

한 해 동안 쌓인 것을 모아 본다. 주소는 `life.bubblelab.dev/review/`.

```
128  가지 일을 끝냈습니다
     ▁▃▅█▆▄▂▇▅▃▂▁   (달마다)

  5  권을 읽었습니다
     [표지][표지][표지][표지][표지]

 12  번 운동했습니다
     한 번에 최고 42개 · 모두 486개
```

## 어디서 읽나

도구들의 저장소를 직접 읽는다. **없는 것은 조용히 건너뛴다** — 도구는 생겼다
없어지므로, 하나가 사라졌다고 한 해 전체가 안 보이면 안 된다.

| 무엇 | 어디 |
| --- | --- |
| 끝낸 일 | `bl_life_v1` 의 `log` |
| 읽은 책 | `bl_library` (IndexedDB) |
| 운동 | `bl_pushup_v1` 의 `log` |

## 셈에서 조심한 것

- **달·해 경계는 KST 자정**이다. 새벽 한 시에 끝낸 일이 전날로 세지 않는다.
- **되돌린 일은 세지 않는다.** 완료를 취소하면 기록도 함께 지워진다 — 잘못 누른
  것까지 "올해 한 일"로 세면 숫자가 거짓말이 된다.
- **최대량 재검사는 운동한 날이 아니다.** 회차를 마친 것만 센다.
- 항목을 지우거나 정리해도 **끝냈다는 기록은 남는다.**
