# 백업 (life/backup)

이 기기에 있는 LIFE 기록 전부를 파일 하나로 내보내고, 그 파일로 되돌린다.
주소는 `life.bubblelab.dev/backup/`.

LIFE 는 서버에 아무것도 저장하지 않는다. 브라우저 데이터를 지우면 전부 사라지고
복구할 방법이 없다 — 그래서 이 도구가 유일한 안전망이다.

## 도구 목록을 두지 않는 이유

도구는 생겼다 없어진다. 어딘가에 목록을 두면 **등록을 잊는 순간 조용히 백업에서
빠지고**, 그 사실은 잃고 나서야 알게 된다. 그래서 이름 규칙으로 찾는다.

```
localStorage   bl_ 로 시작하는 모든 키
IndexedDB      indexedDB.databases() 중 bl_ 로 시작하는 모든 DB
               (오브젝트 스토어·keyPath·키·전체 행)
```

따라오는 성질 두 가지:

- **새 도구는 등록할 곳이 없다.** 저장소 이름을 `bl_` 로 시작하기만 하면 된다.
- **도구를 지워도 그 도구가 남긴 기록은 백업된다.** 코드가 사라졌다고 기록까지
  잃으면 안 되기 때문이다. 나중에 파일에서 되살릴 수 있다.

가져오기는 **덮어쓰기**다 — `bl_` 로 시작하는 것만 지우고 파일 내용으로 바꾼다.
남의 키는 건드리지 않는다. 각 도구는 자기 데이터를 읽을 때 스스로 검사하므로
(`parseState` 등), 형식이 어긋난 항목이 있어도 그 도구만 기본값으로 시작한다.
