# 반도체 (life/semi)

DRAM 이 어떻게 동작하는지 **내가 이해한 것**을 카드로 쌓고, 며칠 뒤에 다시 떠올려
확인한다. 주소는 `life.bubblelab.dev/semi/`. LIFE 의 할 일에 `semi` 를 연결해 두면
그 할 일을 두 번 눌러 바로 열린다.

**공정이 아니라 동작을 본다.** 산화·포토·식각 같은 만드는 순서 대신, 셀에 담긴 전하가
어떻게 밖으로 나오고 어떻게 유지되는지의 흐름으로 주제를 나눴다.

| 주제 | 답해야 할 질문 |
| --- | --- |
| 셀과 어레이 | 1T1C · 워드라인 · 비트라인 · 커패시터에 담기는 전하 |
| 주소와 커맨드 | ACT · RD · WR · PRE 가 각각 무엇을 여닫는가 |
| 센스앰프 | 차지 셰어링 · 읽으면 왜 깨지고 어떻게 되살아나는가 |
| 타이밍 | tRCD · tRP · tRAS · CL · 뱅크를 왜 나눠 쓰는가 |
| 리프레시 | 전하가 새는 속도 · tREFI · 리텐션 |
| 인터페이스 | 프리페치 · 버스트 · DDR · 랭크와 채널 |
| 그 밖에 | 위 어디에도 붙지 않는 것 |

주제는 `store.js` 의 `TOPICS` 한 곳에 있고, **카드가 없는 주제도 자리를 지킨다** —
빈 자리에 그 질문이 그대로 보인다. 다음에 무엇을 볼지가 곧 화면이다.

## 카드 한 장 = 질문 하나에 내 말로 답한 것

옮겨 적은 문서가 아니라 **떠올릴 수 있는 단위**여야 복습이 성립한다. 그래서 제목은
80자, 설명은 800자까지만 받는다. 제목을 질문으로 적으면 복습이 잘 돌아간다
("센스앰프는 왜 필요한가").

**내용은 직접 적는다 — 어디서 끌어오지 않는다.** 이 화면은 외부 API 를 부를 수 없고
(life 의 CSP), 부를 수 있어도 그렇게 하지 않는다. 읽고 이해한 것을 자기 말로 옮기는
것이 목적이라, 붙여넣은 문단은 카드로서 쓸모가 없다.

**출처(선택)** 는 공개된 인터넷 자료의 주소를 적는 자리다. 나중에 "이건 어디서 봤더라"
를 되짚기 위한 것이고, `http(s)` 로 시작하는 주소만 저장된다(링크가 되므로
`javascript:` 같은 것은 `store.js` 에서 막는다).

## 복습은 Leitner 다

`정리 / 복습` 두 장이고, 복습은 제목만 보여 준다. 떠올린 뒤 `확인` 을 누르면 내가
적은 설명이 나오고, 스스로 채점한다.

- **알겠다** → 한 칸 올라간다. 돌아오는 간격은 `0 · 1 · 3 · 7 · 21일`(`BOX_DAYS`).
- **아직** → 0 칸으로 떨어지고, 이번 판의 **맨 뒤로 돌아간다**. 맨 앞에 두면 같은
  카드만 되풀이돼 넘어가지 못한다.
- 큐는 **복습 화면에 들어올 때 한 번** 만들고 그 안에서 돈다. 덜 익은 것부터, 같은
  칸이면 오래 안 본 것부터다 — 순서가 무작위면 어제 못 떠올린 것이 오늘 안 나온다.
- 머리줄의 `익은 것/전체` 에서 익은 것은 마지막 칸까지 올라간 카드다(21일 뒤에 온다).

**답은 자리를 차지한 채 가려만 둔다**(`.veiled`). 확인을 눌러도 아래 버튼이 움직이지
않아야 누르려던 자리가 그대로 있다(life/CLAUDE.md).

## 만듦새

- 규칙(주제·상한·복습 간격·출처 검사)은 `store.js` 순수 함수에만 있다. 화면과
  `_infra/semi.test.mjs` 가 같은 모듈을 쓴다.
- 저장은 localStorage(`bl_semi_v1`) 하나. **서버로 나가는 것은 없다** — 기기끼리
  동기화되지 않고, 백업은 `/backup/` 이 `bl_` 접두사로 담아 간다.
- 깨진 카드는 조용히 버리고 나머지를 살린다. 한 장 때문에 화면 전체가 비면 안 된다.
- 화면 뼈대는 LIFE 의 `../styles.css` 를 물려받는다. 색은 쓰지 않고 밝기로만 나눈다.

```bash
node --test _infra/semi.test.mjs
npx playwright test _infra/e2e/semi.spec.mjs
```
