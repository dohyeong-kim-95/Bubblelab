# 팔굽혀펴기 (life/pushup)

한 번에 **100개**까지 가는 훈련 계획. 주소는 `life.bubblelab.dev/pushup/`.
LIFE 의 할 일에 `pushup` 을 연결해 두면 두 번 눌러 바로 열린다.

## 계획을 어떻게 만드나

구조는 널리 쓰이는 6주 프로그램([hundredpushups.com](https://hundredpushups.com/))에서
가져왔다 — **한 회차 5세트, 세트 사이 60초 휴식, 마지막 세트는 "최대한", 주 3회**.

다만 **수치는 표에서 베끼지 않고 현재 최대량에서 만들어 낸다.** 원본 표는 칸이
셋뿐이라(5개 미만 / 6–10 / 11–20) 재검사로 나온 37개 같은 값에는 줄 것이 없기
때문이다. 대신 같은 모양이 나오도록 맞췄다 — 최대 5개로 시작하면 1일차가
`2 · 3 · 2 · 2 · 3+` 로, 원본 1칸 1일차와 같다(`_infra/pushup.test.mjs` 가 검사한다).

- 첫 회차 목표는 최대량의 60% — 자기 최대치로 시작하지 않는다.
- 회차마다 목표를 **최대 12%**씩 올린다. 더 밀어붙이면 계획이 아니라 희망이 된다.
- 목표가 커질수록 **앞 네 세트를 덜어낸다.** 비율을 고정하면 마지막 회차가
  "70·90·60·60 을 하고 나서 100개"가 되는데 그건 못 할 숙제다.
- 마지막 회차의 목표는 언제나 100개다.

최대 5개 → 32회차(주 3회 기준 약 11주), 최대 20개 → 20회차.

## 쓰는 법

- 회차를 누르면 세트를 하나씩 안내한다. 세트를 마치면 60초를 세어 주고(건너뛸 수 있다),
  마지막 세트는 실제로 한 개수를 적는다 — 그게 최고 기록이 된다.
- **↻ 로 언제든 다시 잰다.** 새 최대량에 맞춰 계획이 다시 만들어지고, 사다리가
  새로 놓이므로 진행은 1일차부터다. 지금까지 한 기록(`log`)은 남는다.

## 만듦새

- 계획·검증·기록은 `store.js` 순수 함수에만 있다. 화면과 테스트가 같은 모듈을 쓴다.
- 저장은 localStorage(`bl_pushup_v1`). 표지 같은 큰 것이 없어 이걸로 충분하다.
- 화면 뼈대는 LIFE 의 `../styles.css` 를 물려받는다.

```bash
node --test _infra/pushup.test.mjs
npx playwright test _infra/e2e/pushup.spec.mjs
```
