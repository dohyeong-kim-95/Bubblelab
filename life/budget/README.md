# 가계부 (life/budget)

**카드 한 장**의 소비를 적고, 한 주기에 정해 둔 한도(기본 100만원)를 지키고 있는지
본다. 주소는 `life.bubblelab.dev/budget/`. LIFE 의 할 일에 `budget` 을 연결해 두면
그 할 일을 두 번 눌러 바로 열린다.

## 답하려는 질문은 하나다

"이 속도로 쓰면 한도를 넘나?" 그래서 합계보다 **기준선**이 먼저 나온다 — 한도를
주기 일수로 고르게 나눈 값이다. 8월(31일)에 100만원이면 10일째의 기준선은
322,581원이고, 그때까지 40만원을 썼으면 **기준보다 77,419원 앞선 것**이다.

화면 위쪽 세 줄이 그 답이다.

- **남은 돈** — 한도에서 쓴 돈을 뺀 값. 넘겼으면 "한도 초과"로 바뀌고 색이 붙는다.
- **막대와 세로선** — 막대는 쓴 비율, 세로선은 오늘까지의 기준선이다. 선보다 왼쪽에서
  멈춰 있으면 잘 가고 있다.
- **한 줄 평** — "오늘까지 기준보다 12만원 덜 썼어요. 남은 9일 동안 하루 78,000원씩
  쓸 수 있어요." 남은 날에 하루 얼마인지는 **오늘을 포함해** 계산한다.

밑의 네 칸은 `쓴 돈 · 하루 가능 · 이 속도면 · 오늘`이다. **이 속도면**은 지금 속도가
주기 끝까지 이어질 때의 금액이라, 한도를 넘길 낌새를 가장 먼저 보여 준다.

## 주기

주기는 달이 아니라 **카드 청구 주기**다. `⚙` 에서 시작일을 바꾸면(1–28) 7/15–8/14
같은 주기가 된다. 적어 둔 것은 날짜로 저장되므로 시작일을 바꿔도 사라지지 않고
주기만 다시 그어진다. 29~31 은 없는 달이 있어 받지 않는다.

`◀ ▶` 로 지난 주기를 다시 본다. 오늘이 든 주기보다 앞으로는 가지 않는다.

## 적는 법

- 금액과 메모를 적고 `＋`. 날짜는 오늘이 기본이고, 지난 주기를 보고 있으면 그 주기
  안으로 맞춰 준다. 적은 것이 지금 보는 주기 밖이면 화면이 그쪽으로 따라간다.
- **환불·취소는 음수로 적는다**(`-30000`). 목록에서는 `+30,000원` 으로, 다른 밝기로
  보인다. 합계에서 그만큼 빠진다.
- 항목을 누르면 금액·메모·날짜를 고치거나 지운다.
- 카드 **한 장**을 전제로 한 화면이라 계좌·카테고리 구분이 없다. 분류가 필요해지면
  그때 요구사항으로 다시 정한다 — 지금은 "얼마나 남았나" 하나만 답한다.

## 카드 문자에서 담기

`✉` 를 누르면 카드 승인 문자를 그대로 읽어 담는다. **브라우저는 문자를 읽을 수 없다**
— 안드로이드에도 SMS 읽기 API 가 없다(Web OTP 는 인증번호 전용). 그래서 자동으로
받아 적는 대신, 문자가 여기 오는 길을 셋 열어 뒀다.

1. **공유 → LIFE** — 손이 제일 덜 간다. 문자 앱에서 문자 하나를 보내도 되고, 문자 백업
   앱(`SMS Backup & Restore`)이 만든 **XML 파일을 그대로 보내도** 된다. 파일은 `POST`
   (multipart)로 오고 서비스워커가 받아 캐시에 잠깐 담은 뒤 `?share=1` 로 넘긴다
   (`life/sw.js`) — 화면은 열리자마자 읽어 확인 목록을 띄운다.
2. **백업 파일 열기** — 선택창에서 직접 고른다.
3. **폴더 기억** — File System Access API 가 있는 브라우저에서 보인다(있는지 물어보고
   켠다. **안드로이드에서도 동작한다** — 2026-08-24 삼성 폰에서 확인). 백업 폴더를 한 번 고르면 손잡이를 IndexedDB(`bl_budget_fs`)에 담아 두고,
   그다음부터는 버튼 한 번에 **그 폴더의 가장 최근 백업 파일**을 열어 읽는다(이름이 아니라
   수정 시각으로 고른다). 브라우저를 껐다 켜면 권한만 한 번 다시 허락하면 된다.

**파일 선택창 자체는 시작 폴더를 정할 수 없다.** 그래서 길이 둘이다 — 파일을 앱으로
보내거나(1번), 폴더 손잡이를 기억하거나(3번). 2번은 둘 다 안 되는 자리의 대비책이다.

**붙여넣기 칸은 두지 않는다.** 기본 문자 앱은 여러 건을 한 번에 글로 빼 주지 않아
(다중 선택은 삭제·전달뿐) 한 건씩 복사하는 꼴이 되고, 그건 직접 적는 것보다 느리다.
공유로 들어온 글은 그대로 같은 파서를 탄다.

`share_target` 은 **앱에 하나뿐인 자리**라 다른 도구가 공유를 받으려면 나눠 주는 화면을
먼저 만들어야 한다. 설치된 PWA 는 매니페스트가 바뀌어도 WebAPK 가 갱신될 때까지
(하루쯤) 새 동작이 오지 않는다 — 그동안은 옛 방식(`?text=`)으로 들어오므로 그쪽도
계속 받는다. 급하면 앱을 지웠다 다시 설치한다.

백업 앱에서는 **카드사 번호 대화만 골라** 백업하면 파일이 작아진다. 파일은 브라우저
안에서만 읽고 서버로 보내지 않는다.

읽은 것은 **담기 전에 목록으로 보여 준다** — 금액·가맹점·날짜를 확인하고 체크를 풀어
뺄 수 있다. 카드사마다 문자 모양이 달라 규칙을 카드사별로 두지 않았다. 어느 문자에나
있는 세 가지를 생김새로 찾는다.

- **금액** — `누적`·`잔액`·`한도` 뒤의 숫자는 건너뛴다(그게 결제액인 줄 알고 담는 것이
  가장 흔한 사고다). `취소`·`환불` 문자는 음수로 담는다.
- **날짜** — `08/23`, `08.23`, `8월 23일`, `2026-08-23` 을 읽는다. 연도가 없으면 오늘을
  넘지 않는 쪽으로 본다(1월에 받은 12월 문자는 작년 것이다). 백업 파일은 문자를 받은
  시각이 들어 있어 그쪽을 쓴다.
- **가맹점** — 시각 뒤에 붙는 것이 가장 흔하다. 그것이 없으면 **가맹점이 아닌 것을 모두
  지우고 남는 말**을 쓴다(카드사·카드번호·이름·금액·날짜·시각·일시불/할부/누적…).
  자리로만 찾으면 **시각이 없는 문자**(자동이체·정기결제)에서 통째로 빗나간다 —
  실제로 `신한카드(3484)승인 김*형님 LG U+통신요금 자동이체 …` 가 문자 원문 그대로
  메모에 들어갔고, 그 표본이 `_infra/budget-sms.test.mjs` 에 남아 있다. 괄호는 깎지
  않는다(`(주)나인투원`). 틀려도 기록을 막지 않는다 — 담은 뒤 눌러서 고치면 된다.

**같은 문자를 두 번 담지 않는다.** 담은 항목에 `날짜T시각-금액` 표식(`sig`)을 남기고,
다음에 같은 문자가 들어오면 "이미 담김"으로 흐리게 보여 준다. 같은 가게에서 같은
금액을 다른 시각에 쓴 것은 다른 결제라 그대로 담긴다.

읽지 못한 문자는 조용히 버리지 않고 몇 건인지와 이유를 보여 준다(인증번호·광고,
원화가 아닌 해외 승인 등). **해외 승인은 담지 않는다** — 환산액이 문자마다 달라 믿을
수 없다.

**카드 대금을 갚은 문자도 담지 않는다.** 즉시결제·선결제를 신청하면 은행에서 카드값이
빠져나가며 문자가 오는데, 그건 쓴 돈이 아니라 이미 쓴 돈을 갚은 것이다 — 담으면 같은
소비를 두 번 세게 된다(이중 계상). `즉시결제·선결제·일부결제·카드대금·결제대금·
이용대금·청구대금` 같은 **대금을 가리키는 말**이 있을 때만 거른다. `출금`·`이체` 만으로는
거를 수 없다 — 체크카드 승인에도 출금이 들어가고, 통신요금 자동이체는 진짜 소비다.

지난 몇 달을 한꺼번에 채우려면 문자보다 **카드사 앱·홈페이지의 이용내역
다운로드(엑셀·CSV)** 가 정확하다. 취소·할부까지 정리돼 있고 문자가 지워졌어도 남아
있다. 지금은 그 파일을 읽지 않는다 — 필요해지면 같은 확인 화면에 붙이면 된다.

## 만듦새

- 주기 긋기·페이스 계산·검증은 `store.js`, 문자 읽기는 `sms.js` 순수 함수에만 있다. 화면과
  `_infra/budget.test.mjs` 가 같은 모듈을 쓴다 — 합계를 화면 안에서 따로 더하지 않는다.
- 저장은 localStorage(`bl_budget_v1`) 하나. **서버로 나가는 것은 없다** — 기기끼리
  동기화되지 않고, 백업은 `/backup/` 이 접두사로 담아 간다.
- 날짜는 전부 `YYYY-MM-DD` 문자열이고 자정 경계는 KST 한 곳(`kstDate`)에서만 다룬다.
  주기 계산은 UTC 기준 일수(`daysBetween`)로만 하므로 서머타임·시차에 흔들리지 않는다.
- 화면 뼈대는 LIFE 의 `../styles.css` 를 물려받는다. 색은 한도를 넘겼을 때만 쓴다.

```bash
node --test _infra/budget.test.mjs _infra/budget-sms.test.mjs
npx playwright test _infra/e2e/budget.spec.mjs
```
