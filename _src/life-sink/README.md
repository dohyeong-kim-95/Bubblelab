# LIFE PC 백업 (life-sink)

폰이 하루 한 번 서버에 올린 백업을 집 PC 로 받아 날짜별 파일로 쌓는 무의존성
Node.js 스크립트다. **서버에는 늘 최신 한 덩어리만 있으므로, 지난 것을 갖는 건
여기뿐이다.**

## 설치

```bash
bash install.sh          # 설정 파일을 만든다
# 앱의 백업 화면 → "PC 용 토큰 발급" → token 에 붙여넣기
bash install.sh          # 다시 실행하면 매시 정각 cron 을 건다
```

`~/life-sink/` 에 `life-backup-YYYY-MM-DD.json` 으로 쌓이고 최근 30개만 남는다.
환경변수 `LIFE_URL` `LIFE_TOKEN` `LIFE_DIR` `LIFE_POLL_MS` 로도 준다.
한 번만 받아 오려면 `node life-sink.mjs --once`.

## 무엇이 담기고 무엇이 안 담기나

담기는 것은 `bl_` 로 시작하는 저장소 전부다 — 할 일과 그 기록, 책 목록, 운동 계획.
도구를 새로 만들어도 등록할 곳은 없다.

**표지 같은 큰 이미지는 담기지 않는다.** 폰이 올릴 때 `data:` 로 시작하는 긴
문자열을 걷어낸다 — 서버로 사진을 올리지 않기 위해서다. 표지를 지키려면 앱의
**파일 내보내기**를 따로 쓴다.

## 안전 장치

- 받은 것이 LIFE 백업이 아니면(게이트가 로그인 HTML 을 돌려줬다든가) **쓰지 않는다.**
- 빈 백업은 거절한다 — 지난 파일을 빈 값으로 덮지 않기 위해서다.
- 임시 파일에 쓰고 fsync 한 뒤 옮긴다. 도중에 죽어도 반쪽 파일이 남지 않는다.
- ETag 를 기억해 안 바뀌었으면 아무것도 쓰지 않는다.
- 파일은 `0600`, 폴더는 `0700`.

**이 폴더 자체는 백업이 아니다.** PC 디스크가 죽으면 함께 사라진다. 클라우드
드라이브 안에 두거나 따로 복사해 두는 편이 낫다.

```bash
node --test _src/life-sink/*.test.mjs
```
