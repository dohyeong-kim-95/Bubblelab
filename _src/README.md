# _src — 배포되지 않는 소스

공개 사이트 폴더에 들어가지 않는 것을 둡니다 — 집 PC 에서 도는 데몬(`duri-sink`·
`papers-sink`·`opic-sink`·`podcast-worker`…)과 로컬 도구입니다. 이 폴더 자체는 배포되지
않습니다. 각 폴더의 README 가 설치·실행 방법의 원본입니다.

번들 단계가 필요한 프로젝트는 지금 없습니다(Vite 로 짓던 아발론은 2026-11-10 에 걷어냈습니다).
다시 생기면 소스는 `_src/<name>/`, 산출물은 공개 폴더에 커밋하고 둘이 같은지 배포에서 검사합니다.
